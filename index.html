🔧 รื้อ risk-free ทั้งเล่ม เงื่อนไขครบแล้ว จึงทำ

รอบเช้าวันนี้จดไว้ว่า: “10Y จริง 4.94% vs โมเดล 4.73% = ห่าง 21bp เกินเกณฑ์แล้ว → รอบถัดไปต้องรื้อ FV ทั้งเล่ม ถ้า 10Y ยังยืนระดับนี้”

สถานะตอนนี้: 10Y ยืน 4.94% (10 ก.ย.) → 4.95–4.96% (11 ก.ย.) = ยืนได้สองเซสชัน → เงื่อนไขครบ → รื้อ

วิธีรื้อ สำคัญกว่าตัวเลข

rf 4.73% → 4.95% (+22bp) · ขยับ พร้อมกัน 3 ค่า: terminal_g + wacc_initial + wacc_terminal ทั้ง base และ bull

ทำไมต้องพร้อมกัน — ถ้าขยับแต่ terminal_g อย่างเดียว ส่วนต่าง (WACCterm − gterm) จะแคบลง → terminal value ระเบิด → FV สูงขึ้นตอนดอกเบี้ยขึ้น ซึ่งกลับหัวกลับหาง

ขยับพร้อมกันทำให้ ส่วนต่างคงเดิม → ผลที่เหลือมาจากการคิดลดกระแสเงินปีต้นล้วน ๆ = FV ลงเล็กน้อยและสมเหตุสมผล (วิธี Damodaran: rf ขึ้นดัน Ke และ Kd ขึ้นด้วย ไม่ได้ดันแค่ g)
